## Github Versioning Messages Cheatsheet

-**build**: Changes that affect the build system or external dependencies (e.g. package.json, CI config).

-**chore**: Miscellaneous tasks: tooling, maintenance, dependency updates that don’t fit “feat” or “fix.”

-**ci**: Continuous Integration config and scripts (e.g. GitHub Actions, Travis).

-**docs**: Documentation only changes (READMEs, wikis, inline docs).

-**feat**: A new feature or user-visible enhancement.

-**fix**: A bug fix.

-**init**: Initial project setup, boilerplate, configuration files, repo scaffolding.

-**perf**: A code change that improves performance.

-**refactor**: Code changes that neither fix a bug nor add a feature (e.g. migrations, cleanup, renames).

-**revert**: Revert a previous commit.

-**style**: Code style/formatting (whitespace, semicolons, etc), linting rules.

-**test**: Adding or updating tests.
